## 🚀 INICIE AGORA (3 Comandos)

### 1. Entre na pasta
```bash
cd GVSolucoes
```

### 2. Instale dependências
```bash
npm install
```
_Isso vai levar 1-2 minutos_

### 3. Rode o servidor
```bash
npm run dev
```

**Pronto!** Abrirá automaticamente em `http://localhost:5173`
